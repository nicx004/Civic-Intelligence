# Project Roadmap

## Phase 1 - MVP

Goal:

Convert complaints into structured tickets after validating that all required information is present.

Features:

- Complaint Intake
- Description Box with Voice Input
- Validation Agent
- Complaint Structuring
- Information Extraction Pipeline
- Department Routing
- Completeness Check Before Ticketing
- Ticket Generation
- Citizen Response

---

## Phase 2 - Jurisdiction Layer

Features:

- Ward Mapping
- Department Mapping
- Municipal Databases

---

## Phase 3 - Graph Layer

Features:

- Neo4j Integration
- Ward → Department → Officer Graph

---

## Phase 4 - Policy Intelligence

Features:

- RAG Pipeline
- SLA Retrieval
- Policy Retrieval

---

## Phase 5 - Evaluation

Features:

- Routing Accuracy
- Extraction Accuracy
- RAGAS Metrics

---

## Phase 6 - Advanced Features

Features:

- Multilingual Complaints
- Duplicate Detection
- Escalation Engine
